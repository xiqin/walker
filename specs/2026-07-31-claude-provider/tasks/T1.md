# Task 1: Claude CLI Driver 核心实现

## 目标

新增 `src/drivers/claude-driver.js`，实现可测试的 Claude Code CLI driver。driver 负责 CLI 探测、sessionRef 创建/恢复、prompt stream-json 解析、参数构造、取消/停止与模型摘要。

## 依赖

无前置任务。

## Affected Files

- `src/drivers/claude-driver.js`
- `test/claude-driver.test.js`

## 实现步骤

## Checklist

- [ ] 新增 `ClaudeDriver extends AgentDriver`，构造函数接收 `runtime`、`execFile`、`spawn`、`env`、`cwd`、`claudeCmd`、`promptTimeoutMs` 等可注入依赖。
- [ ] 实现 `ensureReady()`，用 `execFile(claudeCmd, ['--version'])` 检测版本，超时/ENOENT/非零退出转换为脱敏诊断错误或 false 状态。
- [ ] 实现 `createSession()`、`resumeSession()`、`listSessions()`，返回并维护 Walker 可持久化的 `agentRef`，字段包含 `provider`、`claudeSessionId`、`cwd`、`model`、`agent`、`permissionMode`、`createdAt`、`updatedAt`。
- [ ] 实现 `prompt(sessionRef, text, options)`，使用 `spawn(claudeCmd, argv, { shell: false })` 执行 `--print --output-format stream-json`，并按 sessionRef 传 `--resume` 或 `--session-id`。
- [ ] 实现 stream-json line parser，将文本、reasoning、tool use、permission/status、error、done 映射为 `AgentEvent`；未知 JSON 事件映射为 status 或忽略，但不得使成功任务失败。
- [ ] 实现 `stop()`、`cancel()`、`delete()`，用 pending map 终止子进程并保证重复调用幂等。
- [ ] 实现 `listModels()`，返回 `sonnet`、`opus` 以及配置注入模型摘要，不伪造远端模型目录。
- [ ] 所有错误输出经过脱敏，至少覆盖 token、secret、api key 常见环境键和值。

## Acceptance Mapping

覆盖 `REQ-002`、`REQ-003`、`REQ-004`、`REQ-005`、`REQ-006`、`REQ-009` 中与 driver 核心、CLI 探测、会话、prompt、参数安全、取消清理和 fake CLI 测试相关的 behavior。

## 测试步骤

1. 新增 `test/claude-driver.test.js`，用 fake `execFile` 覆盖 `ensureReady()` 成功、ENOENT、超时、非零退出和脱敏。
2. 用 fake `spawn` 覆盖 prompt argv 构造、空值跳过、危险权限默认不传、`shell` 不启用。
3. 用 fake stdout JSON lines 覆盖 text/done、未知事件容错、stderr 非零退出、失败诊断上下文。
4. 用 fake child process 覆盖 stop/cancel/delete 幂等、pending 清理、取消后再次 prompt。

## 完成标准

`test/claude-driver.test.js` 覆盖本任务列出的 behavior，且不调用真实 Claude prompt。
