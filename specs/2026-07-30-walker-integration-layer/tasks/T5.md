# Task 5: EventBus 与 WebSocket 事件流

## 描述

在现有 `event-store` 之上增加非阻塞 EventBus，并提供认证的 `/api/v1/events/stream` WebSocket 实时事件流，支持过滤、心跳、断开清理和脱敏。

## 依赖

- 前置 task：T3
- 外部依赖：`ws` npm 依赖、Admin HTTP server upgrade 事件

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 创建 | `src/events/event-bus.js` | 实现 publish/subscribe/unsubscribe 和 listener 隔离。 |
| 创建 | `src/admin/ws-events.js` | 实现 WS 认证、订阅过滤、心跳、脱敏和断开清理。 |
| 修改 | `src/admin/server.js` | 在 Admin server 中挂载 upgrade 处理能力。 |
| 创建 | `test/event-bus.test.js` | 覆盖非阻塞 publish、抛错 listener 隔离和 unsubscribe。 |
| 创建 | `test/events-websocket.test.js` | 覆盖认证、广播、过滤、脱敏、断开清理和错误记录。 |

## 复杂度

high，原因：涉及实时连接生命周期、认证和性能隔离，且不能阻塞 prompt 主流程。

## 实现步骤

- [ ] 实现 EventBus，确保 publish 不等待慢 listener，单 listener 抛错不影响其他 listener。
- [ ] 调整事件记录集成点，使 `recordEvent()` 或 appContext 事件发布同时写入 store 与 bus。
- [ ] 实现 `/api/v1/events/stream` upgrade 处理，复用 admin token 认证。
- [ ] 支持客户端 subscribe 消息，按 sessionId、routeKey、level、type 过滤。
- [ ] 广播前复用脱敏逻辑，避免 token、secret 或敏感环境变量泄露。
- [ ] 实现 ping/pong 心跳和 close/error 后 unsubscribe。
- [ ] 记录连接、订阅、断开和发送失败事件或日志。
