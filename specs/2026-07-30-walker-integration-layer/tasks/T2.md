# Task 2: Doctor CLI 与 provider 命令

## 描述

新增 `walker doctor`、`walker providers list`、`walker providers doctor [id]` 命令，并在 CLI 入口预留 `walker init` 调度，形成可读、脱敏、可恢复的诊断输出。

## 依赖

- 前置 task：T1
- 外部依赖：Node.js 版本、环境变量、本机 provider 命令

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 修改 | `src/index.js` | 增加 doctor、providers、init 命令分发和 usage 文案。 |
| 创建 | `src/cli/doctor-command.js` | 聚合 Core、Platforms、Providers、Suggestions 检测并返回退出码。 |
| 创建 | `src/cli/providers-command.js` | 实现 `providers list` 与 `providers doctor [id]`。 |
| 创建 | `src/cli/cli-output.js` | 统一表格、状态、脱敏和错误输出格式。 |
| 创建 | `test/doctor-cli.test.js` | 覆盖 doctor 输出、脱敏、恢复路径和只读行为。 |
| 创建 | `test/providers-cli.test.js` | 覆盖 providers list、unknown provider 和非零退出码。 |

## 复杂度

medium，原因：主要是 CLI 编排和输出格式，但必须严格保持只读安全边界和现有命令兼容。

## 实现步骤

- [ ] 在 `src/index.js` 增加 `doctor`、`providers`、`init` 命令分发，保留现有 start/stop/status/logs/help 行为。
- [ ] 实现 doctor core 检测：Node.js 版本、数据目录、admin token、飞书环境变量、默认 cwd。

- [ ] 确认 doctor 默认只读，不写配置、不写第三方密钥。
