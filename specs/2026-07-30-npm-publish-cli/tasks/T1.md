# T1 增加 npm 发布前校验脚本

## 目标

在 `package.json` 中增加 npm 生命周期脚本，使打包和发布前都执行现有完整测试链路。

## 涉及文件

- `package.json`

## 实现步骤

1. 在 `scripts` 中增加 `prepack`，命令为 `npm test`。
2. 在 `scripts` 中增加 `prepublishOnly`，命令为 `npm test`。
3. 不改变现有 `start`、`test`、`lint`、`check` 脚本语义。

## 验收映射

- REQ-001-B01：`package.json` 暴露 `prepack` 和 `prepublishOnly`，二者均执行 `npm test`。
- REQ-001-B02：发布前校验复用 `npm test`，不绕过 lint/check。
- REQ-001-B03：`prepack` 和 `prepublishOnly` 保留 `npm test` 失败退出码传播，不吞掉失败。

## 验证

- `npm test`
- `npm pack --dry-run`
