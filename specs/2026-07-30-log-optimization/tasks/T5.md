# T5 Admin 日志页面清空按钮

## 目标

在 Admin 活动与日志页面新增“清空日志”按钮，点击后调用后端清空接口，成功后刷新日志内容，失败时展示可见错误，并避免重复提交。

## 实现要求

- 修改 `src/admin/public/js/pages/logs.js`，在现有 toolbar 中增加“清空日志”按钮。
- 点击按钮调用 T4 新增的 Admin 清空日志接口，不携带搜索词、级别、来源、行数等筛选参数。
- 清空请求进行中按钮进入 disabled 或 busy 状态，重复点击不发起第二个请求。
- 清空成功后显示成功反馈，并重新调用 `refreshLogs()`。
- 清空失败时显示失败反馈，不把现有日志内容错误替换为空。
- 更新页面说明文案，说明默认查看当前日志文件；不得承诺读取归档内容。
- 保留现有筛选、导出、自动刷新和 cleanup 行为。

## TDD 步骤

1. 在 `test/admin-ui-workspaces.test.js` 中覆盖页面渲染“清空日志”按钮。
2. 覆盖点击按钮调用清空接口，且不传筛选参数。
3. 覆盖清空成功后再次请求 `/api/admin/logs` 并显示成功反馈。
4. 覆盖清空失败时显示错误且保留当前日志内容。
5. 覆盖接口挂起时重复点击只发起一次请求。
6. 修改 `src/admin/public/js/pages/logs.js` 使测试通过。
