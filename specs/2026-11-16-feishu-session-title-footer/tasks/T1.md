# Task 1: 统一标题页脚与替换兼容

## 描述与依赖

在飞书平台层统一生成带标题的页脚，保持文本与卡片一致。无前置任务，无新增外部依赖。

## 涉及文件

修改 `src/platform/feishu/api.js` 及其现有平台测试 `test/feishu-api.test.js`；不得改写其他任务拥有的文件。

## 实现步骤

- [ ] 让 `buildRuntimeFooter` 接受可选 `runtime.sessionTitle`；仅有效字符串生成会话行，顺序固定为会话、模型、上下文。
- [ ] 将回车、换行等行分隔折叠为单行；按普通展示文本处理 Markdown/飞书标签字符，保证卡片结构和页脚字段数量不受标题影响。
- [ ] 让文本末尾及卡片字段识别同时支持旧格式和新增会话行的格式；重复更新仅保留最新页脚，不修改正文或输入卡片。
- [ ] 保持模型与上下文计算和无标题格式不变；新增函数添加中文用途和参数说明，避免为测试引入接口或抽象。
