# Task 2: 关联会话标题透传与回复去重

## 描述与依赖

依赖 T1 的可选 `runtime.sessionTitle` 页脚接口，从消息所属会话透传标题，并保持正文去重兼容。无新增外部依赖。

## 涉及文件

修改 `src/dispatch/message-dispatcher.js` 与 `test/message-dispatcher.test.js`；只读平台页脚及卡片调用链，不修改它们。

## 实现步骤

- [ ] 在 `_feishuRuntimeContext` 使用 `_sessionFromFeishuContext` 已解析会话的 `title`，返回可选 `sessionTitle`；保留会话解析优先级、模型回退及上下文计算。
- [ ] 不为标题新增远端调用、写入会话数据或使用无关焦点会话；无关联会话的系统消息仍使用旧页脚。
- [ ] 更新 `_normalizeDeliveredText`，只剥离末尾结构完整的新旧页脚，保留正文里的模型文字和非页脚内容；同正文标题改变不触发补发。
- [ ] 确认问题卡与进度卡沿现有运行时入口取得标题，不新增独立标题消息，不改变路由/绑定/插件协议。
- [ ] 做最小重构和设计检查，新增函数遵守中文注释要求，不增加测试专用接口。
