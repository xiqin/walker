# Task 1: 删除运行时模块并拆除启动接线

## 描述

删除 Claude driver、PTY、bridge、attach 和 transcript 模块，并让应用启动、关闭、Windows 终端和 CLI 不再连接 Claude。

## 依赖

- 前置 task：无
- 外部依赖：无

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 删除 | `src/drivers/claude-*.js` | 删除 6 个 Claude 运行时模块 |
| 删除 | `src/cli/claude-attach-command.js` | 删除 attach CLI 实现 |
| 修改 | `src/app/bootstrap.js` | 不再构造或注册 Claude，关闭时不释放 Claude |
| 修改 | `src/index.js` | `claude` 子命令返回移除错误，帮助删除 attach 行 |
| 修改 | `src/runtime/windows-runtime.js` | 删除 `openClaudeAttachTerminal` |
| 修改 | `src/drivers/stub-drivers.js` | 删除 `stubClaudeDriver`，保留 Codex stub |
| 删除 | `test/claude-*.js` 与 `test/cli-claude-attach.test.js` | 删除只覆盖已删模块的测试 |
| 修改 | `test/bootstrap.test.js` | 断言不再注册 Claude，Codex 仍在 |
| 修改 | `test/opencode-driver.test.js` | 去掉已删除的 `stubClaudeDriver` 依赖，只保留 Codex stub 断言 |
| 修改 | `test/runtime.test.js` | 删除 attach 终端测试并确认不再 spawn |
| 创建 | `test/cli-removed-claude.test.js` | 覆盖 CLI 移除后的退出码、消息和 token 不泄露 |

## 复杂度

high，原因：bootstrap 关闭顺序和多份 Claude 测试同时拆除，遗漏一处 require 就会导致启动失败。

## 实现步骤

- [ ] 删除 Claude 专用源文件和只引用这些文件的测试。
- [ ] 从 `bootstrap.js` 去掉 Claude require、bridge 构造、driver 注册和关闭释放。
- [ ] `createApp` 只注册 opencode 与 codex。重复 `stop` 不调用 Claude 方法，也不打开 `claude --resume` 终端。
- [ ] 删除 `WindowsRuntime.openClaudeAttachTerminal`，不再写入 `WALKER_CLAUDE_ATTACH_URL` 或 `WALKER_CLAUDE_ATTACH_TOKEN`。
- [ ] `walker claude` 与 `walker claude attach` 一律退出码 1，输出 `Claude integration has been removed.`，不读取 attach URL，不创建 WebSocket。
- [ ] `walker help` 不再包含 `claude attach`。
- [ ] `stub-drivers.js` 只导出 `stubCodexDriver`。
- [ ] 启动前后比较已有 `agent=claude` store 记录，确认 id、agentRef 和状态不变。
- [ ] 静态确认 `src/` 不再 require 已删除模块。
