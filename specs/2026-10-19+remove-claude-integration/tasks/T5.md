# Task 5: Admin 会话本地生命周期与连接页

## 描述

Admin 不再创建 Claude 底层会话。旧记录可以本地停止和删除，prompt 在鉴权之后、driver 之前拒绝。连接页不再把 Claude 列为可用接入。

## 依赖

- 前置 task：无
- 外部依赖：无

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 修改 | `src/admin/session-admin.js` | 创建前拒绝；stop、delete、prompt 不调用 Claude driver |
| 修改 | `src/admin/core-routes.js` | 创建失败时返回错误信封，不再包进 success |
| 修改 | `src/api/v1/sessions-routes.js` | 创建失败时返回错误信封，不再包进 sendOk |
| 修改 | `src/api/v1/prompt-routes.js` | `claude_removed` 返回精确错误信封，不再变成 500 |
| 修改 | `src/admin/public/js/pages/connections.js` | 连接列表移除 claude |
| 修改 | `test/admin-core-api.test.js` | 用移除后的断言替换旧 Claude 创建和可用性断言 |
| 修改 | `test/api-v1.test.js` | 断言公开创建接口返回 claude_removed 且不写 store |

## 复杂度

medium，原因：创建、停止、删除和 prompt 的失败点不同，必须避免先写 store 再失败。

## 实现步骤

- [ ] `createSession` 在 `sessionService.createSession()` 之前拒绝精确 `agent=claude`，返回 `claude_removed`，session 数不变。
- [ ] `sendPrompt` 在 `registry.get()` 之前对 `agent=claude` 返回 `claude_removed`，不记录成功的 `web prompt sent`。
- [ ] `stopSession` 与 `deleteSession` 对 `agent=claude` 只改 Walker store，不调用 driver.stop 或 driver.delete。
- [ ] 列表仍能返回旧记录。若 Admin 会话摘要展示 agent，保留 `claude` 原值，并在可诊断字段或 warning 中包含统一移除消息。
- [ ] 未认证创建请求保持原有 401，store 不变。
- [ ] 注入名为 claude 的 driver 时，stop、delete、prompt 调用次数为 0。
- [ ] `connections.js` 的 agent 列表只保留 opencode 与 codex，删除“Claude Code CLI，未来实现”。
