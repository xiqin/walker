# Task 3: 停止解析和编辑 Claude 配置

## 描述

配置加载和管理端编辑不再认识 `CLAUDE_*`。`WALKER_DEFAULT_AGENT=claude` 失败关闭，且任何失败都不改写 `.env`。

## 依赖

- 前置 task：无
- 外部依赖：无

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 修改 | `src/config/env.js` | 删除 claude 字段和 permission parser；默认 agent 为 claude 时抛错 |
| 修改 | `src/admin/config.js` | 删除 claude 分组和全部 CLAUDE_* 字段 |
| 修改 | `src/admin/config-editor.js` | 删除 `claude-permission-mode` 分支 |
| 修改 | `.env.example` | 删除 Claude Code 配置段 |
| 修改 | `test/config-env.test.js` | 覆盖忽略残留键和默认 agent 拒绝 |
| 修改 | `test/admin-observability-config.test.js` | 摘要不再含 Claude |
| 修改 | `test/admin-config-event.test.js` | PATCH Claude 键失败且文件不变 |

medium，原因：要同时处理解析、摘要、allowlist 和失败原子性，但不能误伤 OpenCode 与飞书配置。

## 实现步骤

- [ ] 删除 `parseClaudePermissionMode` 和 `loadEnvConfig` 返回对象中的全部 `claude*` 字段。
- [ ] `WALKER_DEFAULT_AGENT` 精确等于 `claude` 时抛出 `code=claude_removed`、消息为 `Claude integration has been removed.` 的 Error。
- [ ] 其他 `CLAUDE_*` 残留不进入结果对象，也不导致加载失败。
- [ ] 管理端 groups、fields、editableKeys 不再包含 claude 或 `CLAUDE_*`。
- [ ] PATCH 只含 `CLAUDE_*` 时返回现有非法字段错误，临时 `.env` 字节哈希不变。
- [ ] 错误、摘要和日志不回显 `CLAUDE_*` 值中的哨兵。

- [ ] 先用 claude 默认 agent 确认失败，再改回 `opencode` 并保留 `CLAUDE_CMD`，第二次加载成功。
- [ ] `.env.example` 删除 Claude 段，保留 OpenCode 与飞书示例。
