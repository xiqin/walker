# Task 1: attach 强制无历史回放

## 描述

把用户 attach 连接固定为仅订阅连接后的实时 PTY 数据，并证明标准 attach server 与 bridge sidecar attach 的鉴权、未知参数和超大 replay 缓冲均不能泄露历史 ANSI 字节。

## 依赖

- 前置 task：无
- 外部依赖：现有 `ws` 与 `ClaudePtyBroker` 接口

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 修改 | `src/drivers/claude-attach-server.js` | 将 attach 输出订阅固定为无 replay，并保持实时字节原样转发 |
| 修改 | `src/drivers/claude-bridge-sidecar.js` | 将 bridge sidecar attach 输出订阅同样固定为无 replay |
| 修改 | `test/claude-attach.test.js` | 增加连接前后输出、鉴权、参数与历史大小测试 |
| 修改 | `test/claude-bridge-sidecar.test.js` | 覆盖 sidecar attach 不回放历史且转发实时输出 |

## 复杂度

medium，原因：代码改动很小，但需验证 WebSocket 时序、鉴权失败和协议绕过边界。

## 实现步骤

- [ ] 在测试 broker 中预置连接前 ANSI 数据，建立 attach 后断言客户端初始收到 0 字节。
- [ ] 将标准 attach server 与 bridge sidecar attach 的 `subscribeOutput` 调用均改为固定 `replay: false`，不接受客户端覆盖。
- [ ] 验证连接后的二进制 PTY 数据仍原样转发，resize 和输入路径不受影响。
- [ ] 覆盖空 replay、1 MiB replay、`replay=true` 查询参数、未知参数和无效 token。
- [ ] 检查日志不包含 attach token。
