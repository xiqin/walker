# Task 4: claude/kscc 与 OpenCode 回归边界

## 描述

参数化验证 `CLAUDE_CMD=claude` 与 `CLAUDE_CMD=kscc` 均使用相同单 PTY 和无回放 attach 语义，不尝试 Remote Control、不修改认证端点，并证明 OpenCode provider 无行为变化。

## 依赖

- 前置 task：T1、T2、T3
- 外部依赖：无真实 Claude/kscc 网络调用，全部使用 fake CLI/runtime

medium，原因：不改生产模块，但需跨 CLI、driver、环境传递和 OpenCode 测试集建立明确回归证据。
