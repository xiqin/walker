# Task 1：精确只读标题能力

## 描述、层级与依赖

驱动层为已关联会话提供只读标题查询；无前置任务，无新 npm 依赖。复杂度 medium：涉及现有认证、两种传输和实际超时，但生产改动仅一个文件。

## 涉及文件

修改 `src/drivers/opencode-driver.js`，新增有中文参数说明的 `getSessionTitle(sessionRef, options)` 及仅此功能需要的局部帮助方法。实现重构后在既有 `test/opencode-driver.test.js` 验证并产出 `evidence/driver-validation.md`；此处仅声明归属，不预设计测试名称或 seam。依赖读取文件见 frontmatter，不修改公共 HTTP 客户端、驱动基类或消息读取。经用户另行批准，允许修改共享 `src/core/http-helper.js` 及 `test/http-helper.test.js`，只修复跨UTF-8分块和JSON解析失败原始正文日志两项阻断，必须保留字节限制、超时与原返回契约；详见 `http-scope-amendment.md`。

## 实现步骤

用户追加批准修改 `test/claude-removal-guard.test.js`：移除“驱动相对HEAD无改动”的历史验收断言及其无用Git帮助代码，保留所有Claude禁接入、禁止真实启动、禁止读取用户目录及历史资料保护。见 `guard-scope-amendment.md`。

- [ ] 按 `plan.md` 固定接口实现 `Promise<string|null>`；明确 ID 不存在时不发请求，不产生默认标题。
- [ ] 普通连接使用已有客户端、关联地址、编码 ID、剩余超时和 GET；解析官方双层 data，兼容直接 data 对象；存在响应 ID 时验证与请求相符。
- [ ] TUI 直接选择已有库，使用只读 URI、精确 ID 安全转义、`SELECT hex(title)` 与 UTF-8 解码；不依赖 `-readonly` 或 JSON 扩展。
- [ ] 设置真实 HTTP 超时和 SQLite 进程终止/输出上限；失败保留受控错误分类供调度层使用，禁止改查另一来源、枚举会话或启动服务。
- [ ] 保持现有认证、其他请求与消息读取行为，做局部重构并审查接口只有一个真实用途：关联会话标题查询，不引入泛化策略框架。
