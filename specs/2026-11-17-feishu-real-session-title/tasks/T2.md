# Task 2：归属、缓存与页脚接入

## 描述、层级与依赖

调度层将真实标题加入所有共用运行时上下文，保证多会话隔离和失败不阻断。依赖 T1 已实现接口；复杂度 high，涉及并发、生命周期与旧行为不变量，无新增第三方依赖。

## 涉及文件

生产代码仅修改 `src/dispatch/message-dispatcher.js`，涵盖构造、`_feishuRuntimeContext`、`_sessionFromFeishuContext`、局部标题帮助方法和 `destroy`。实现后在既有 `test/message-dispatcher.test.js` 验证，产出 `evidence/dispatch-validation.md`；具体测试名和隔离方式在实现重构后确定。保持飞书 API 与问题处理器只读，不修改外部协议。

## 实现步骤

- [ ] 任何异步等待前固定所属会话及连接快照；显式失效身份不再落入焦点，route-only 兼容调用只在入口解析一次。
- [ ] 按 `plan.md` 组合键隔离端点、runtime、数据库与会话 ID，调用 T1；没有驱动能力的既有替身/驱动仅本地降级。
- [ ] 实现一个128项有界集合、16项进行中读取、同键合并、完成后30秒成功/失败缓存、已完成条目LRU和饱和立即降级；历史标题不另设存储。
- [ ] 共享2秒截止时间与真实源超时，清理等待定时器；超时、销毁或请求身份不再匹配的结果不得发布。
- [ ] 实现有效标题与关联ID占位名判断；按同身份历史、有效本地、无标题降级。不同 Walker 本地标题不得写入真实标题缓存。
- [ ] 仅构造可选 `runtime.sessionTitle`；保持模型补读及其既有更新、上下文、安全转义、去重和进度卡补位原样。
- [ ] 销毁唤醒等待、清空集合并防止迟到重填；日志使用受控类型和关联ID，不记录异常全文、URL、认证或正文。
- [ ] 局部重构并做测试前设计审查，不增加为了测试而设的配置、构造注入、通用缓存抽象。
