# Task 1: Claude 托管 runtime 与本地 attach 基座

## 描述

固化 Walker 托管 Claude TUI runtime 的所有权、可写状态、生命周期日志和本地 attach/replay 能力，为后续飞书写入同一 PTY 提供可靠基座。

## 依赖

- 前置 task：无
- 外部依赖：Claude CLI、PTY runtime、WebSocket loopback bridge

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 修改 | `src/drivers/claude-pty-broker.js` | runtime owner/inputWritable/status 字段、不可写保护、attach/replay 边界 |
| 修改 | `src/drivers/claude-bridge-sidecar.js` | attachment 快照、loopback attach、write/subscribe 状态与日志 |
| 修改 | `test/claude-pty-broker.test.js` | runtime lifecycle、replay、不可写与禁止 resume 测试 |
| 修改 | `test/claude-bridge-sidecar.test.js` | attach token、write/subscribe、detach/re-attach 测试 |
| 修改 | `test/claude-tui-reconnect.integration.test.js` | reconnect/attach 不改变 runtime 归属的集成测试 |

## 复杂度

high，原因：这是跨 PTY、bridge、runtime 状态和 attach/replay 的基础改造，错误会影响所有 Claude 输入输出。

## 实现步骤

- [ ] 为 Claude runtime snapshot 增加 `owner`、`inputWritable`、`status` 一致性字段，并保证 create/update 原子生效。
- [ ] 明确 `starting`、`active`、`detached`、`stopped`、`error` 的可写规则，非 active 可写场景必须有显式 reconnectable 判断。
- [ ] 保证 attach/detach 只影响客户端连接，不停止 Claude runtime，不改变 route/session 归属。
- [ ] 为 output replay 设置边界测试，确保 replay 不返回无限历史且多个订阅者互不阻塞。
- [ ] 为 runtime 创建、停止、不可写、attach 失败添加结构化日志并验证敏感值不泄漏。
