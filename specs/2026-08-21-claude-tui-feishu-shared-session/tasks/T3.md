# Task 3: AskUserQuestion hook/transcript 捕获与 tool_result 归一化

## 描述

补齐 Claude 问题事件的早期捕获、transcript fallback、真实 `tool_result` ACK 归一化和脱敏日志，为 dispatch 状态机提供可靠事件输入。

- 前置 task：T1
- 外部依赖：Claude transcript JSONL、Claude hook payload

## 复杂度

medium，原因：事件解析逻辑集中但必须兼容真实 Claude JSONL 变化和敏感字段脱敏。

## 实现步骤

- [ ] 归一化 AskUserQuestion hook payload 为标准 question event，保留 toolUseId/requestID/questions/options。
- [ ] 保留 transcript `AskUserQuestion` fallback，并在事件中标注 source。
- [ ] 解析 matching `tool_result` 为 ACK event，用于后续状态机确认。
- [ ] 对重复 question/tool_result 做幂等标识，避免重复卡片或重复终态。
- [ ] 为 hook 丢失、partial line pending、fallback 来源和脱敏添加测试。
