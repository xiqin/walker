# Task 1: FeishuApi 页脚构建与 payload 注入

## 描述

在 `FeishuApi` 层实现统一运行信息页脚，并在文本、Markdown 和交互卡片发送或更新 payload 中完成幂等注入。

## 依赖

- 前置 task：无
- 外部依赖：无

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 修改 | `src/platform/feishu/api.js` | 增加页脚格式化、模型和上下文安全解析、文本和卡片 payload 注入逻辑。 |

## 复杂度

medium，原因：同一文件内覆盖多种飞书 payload 形态，并且需要保持分片、卡片结构和 token 获取行为不变。

## 实现步骤

- [ ] 增加页脚标记常量与纯函数，输出包含 `模型` 和 `上下文` 的统一 markdown/text 片段。
- [ ] 增加模型解析函数，支持对象 `{ providerID, modelID }`、字符串 `provider/modelID`、普通字符串、默认模型和异常回退 `unknown`。
- [ ] 增加上下文大小解析函数，支持 `contextSize`、`contextTokens`、`tokenUsage`、`usage` 等当前调用可传入字段，并在缺失或异常时返回 `unknown`。
- [ ] 修改 `replyText`、`sendText`、`replyMarkdown`、`sendMarkdown`，在 `splitTextChunks` 前对原文本追加一次页脚。
- [ ] 修改 `replyCard`、`patchCard`，向 `card.body.elements` 末尾幂等追加 markdown 页脚元素，不改变原有 header/config/body 其他字段。
- [ ] 确保页脚注入仅处理内存对象或字符串，不新增网络请求或 driver 调用。
