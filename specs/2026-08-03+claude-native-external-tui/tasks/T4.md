# Task 4: 精确 UUID JSONL 观察与轮次回复

## 描述

实现基于 canonical cwd、Claude配置根目录和精确 `claudeSessionId` 的 JSONL transcript 读取与 watcher，替代目录mtime猜测并支持飞书/本地TUI轮次观察。

## 依赖

- 前置 task：T1、T3
- 外部依赖：无新增

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 创建 | `src/drivers/claude-transcript.js` | Claude project路径解析、UUID校验、边界读取、部分行容错和watcher |
| 创建 | `test/claude-transcript.test.js` | JSONL fixture覆盖边界读取、路径安全、部分行、同cwd多UUID隔离 |

## 复杂度

high，原因：transcript 是飞书回复和本地TUI观察的唯一语义来源，必须防串线和路径越界。

## 实现步骤

- [ ] 步骤 1：实现 `resolveClaudeTranscriptPath({ cwd, configDir, claudeSessionId })`，要求UUID合法、路径位于配置根目录和预期 project 目录。
- [ ] 步骤 2：实现 prompt 边界读取：记录提交前文件offset或消息序号，只返回边界后的assistant文本，过滤旧消息和prompt echo。
- [ ] 步骤 3：实现 watcher：本地TUI追加的user/assistant JSONL记录形成可路由事件，供 `ClaudeDriver.watchSession()` 使用。
- [ ] 步骤 4：部分行、文件缺失和写入超时返回明确错误，watcher继续工作，不读取替代session文件。
- [ ] 步骤 5：同 cwd 多个 UUID 时只读取绑定 UUID，禁止按最新mtime选择文件。
