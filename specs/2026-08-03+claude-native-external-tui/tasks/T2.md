# Task 2: 本机 attach 协议、CLI 与外部窗口入口

## 描述

实现本机 attach server、`walker claude attach <runtime-id>` 客户端和 Windows 外部 attach 窗口启动入口，使终端窗口只作为 PTY 的视图和键盘转发器。

## 依赖

- 前置 task：T1
- 外部依赖：现有 `ws`

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 创建 | `src/drivers/claude-attach-server.js` | 本机 WebSocket 端点、token认证、二进制帧协议、resize和detach处理 |
| 创建 | `src/cli/claude-attach-command.js` | attach CLI客户端，raw stdin、stdout渲染、resize上报和错误退出码 |
| 修改 | `src/runtime/windows-runtime.js` | 新增 Claude 专用 attach 窗口方法，不改变 `openTerminal()` |
| 修改 | `src/index.js` | 注册 `claude attach` 子命令 |
| 创建 | `test/claude-attach.test.js` | attach server协议、认证、断线和畸形帧测试 |
| 修改 | `test/runtime.test.js` | 覆盖新增窗口方法并确保 `openTerminal()`旧语义不变 |
| 创建 | `test/cli-claude-attach.test.js` | attach CLI参数校验、错误退出码和无效runtime测试 |

## 复杂度

high，原因：需要同时处理本地安全、二进制终端字节、CLI raw mode和不影响旧 runtime 行为。

## 实现步骤

- [ ] 步骤 1：实现 attach server，默认只监听 `127.0.0.1`，握手必须携带 broker 生成的高熵 token。
- [ ] 步骤 2：定义最小协议：PTY输出二进制下发、键盘二进制上行、resize控制消息、close/error状态消息。
- [ ] 步骤 3：实现 attach CLI，缺 runtime ID、认证失败或协议错误时返回非零退出码。
- [ ] 步骤 4：在 WindowsRuntime 新增 Claude 专用外部 attach 窗口方法，命令形态为运行 `walker claude attach <runtime-id>`，失败不关闭 runtime。
- [ ] 步骤 5：补充敏感值扫描测试，确保 token、完整 prompt 和敏感 env 不进入日志或 agentRef。
