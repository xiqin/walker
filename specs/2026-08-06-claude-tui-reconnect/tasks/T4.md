# Task 4: attach CLI 断线重连

## 描述

增强 `walker claude attach <runtimeId>`，在 WebSocket 断开后按限定恢复窗口重新解析本地 attach 端点并重连。

## 依赖

- 前置 task：T1
- 外部依赖：现有 `ws` 包

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 修改 | `src/cli/claude-attach-command.js` | 增加重连循环、恢复窗口、raw mode 安全释放和脱敏错误。 |
| 创建 | `test/claude-attach-command.test.js` | 覆盖 close 后重连、持续失败退出、raw mode 恢复和 token 错误脱敏。 |

## 复杂度

medium，原因：CLI 状态机较小，但需处理 stdin/stdout/raw mode 和异步 WebSocket 生命周期。

## 实现步骤

- [ ] 把单次 WebSocket 连接改为可重复 `connect()` 的状态机。
- [ ] 增加可注入 `reconnectWindowMs`、`retryDelayMs`、`setTimeout`，便于测试恢复窗口和超时。
- [ ] WebSocket 非正常 close 后重新调用 `resolveAttachment(runtimeId)`，成功则创建新 WebSocket。
- [ ] 持续失败超过恢复窗口后退出非零，并释放 raw mode、暂停 stdin。
- [ ] 对 authorization/token 失败输出脱敏错误，不打印 token 或完整敏感 URL。
- [ ] 编写 CLI 单元测试。
