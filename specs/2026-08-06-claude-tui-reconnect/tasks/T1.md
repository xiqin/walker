# Task 1: Claude bridge/sidecar 控制面基础

## 描述

新增 Claude 本地 bridge/sidecar 控制面，承载可跨 Walker 重启存活的 runtime registry、attach/control WebSocket、本地凭据校验与脱敏状态快照。

## 依赖

- 前置 task：无
- 外部依赖：现有 `ws` 包、Node.js loopback HTTP/WebSocket

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 创建 | `src/drivers/claude-bridge-sidecar.js` | 实现本地 sidecar 控制面、runtime registry、attach/control 连接和安全校验。 |
| 创建 | `test/claude-bridge-sidecar.test.js` | 覆盖 runtime 发现、可重连状态、本地连接限制、token 校验和脱敏输出。 |

## 复杂度

high，原因：该任务定义后续 driver、attach CLI 和 shutdown 生命周期依赖的核心接口与安全边界。

## 实现步骤

- [ ] 定义 `ClaudeBridgeSidecar` 构造参数、`start()`、`stopWalkerConnection()`、`registerRuntime()`、`getRuntime()`、`listRuntimes()`、`writeInput()`、`subscribeOutput()`、`createAttachment()` 等最小接口。
- [ ] 实现 runtime 快照，包含 `runtimeId`、`claudeSessionId`、`status`、`processGeneration`、`cwd`、`reconnectable`、`lastSeenAt`，不包含 token 或敏感环境变量。
- [ ] 实现 loopback-only 连接校验，拒绝非本地 remoteAddress。
- [ ] 实现 attach/control token 校验，缺失或错误 token 时拒绝连接并返回脱敏错误。
- [ ] 实现 shutdown 半清理保护：Walker 连接断开时 runtime registry 保持可诊断状态，pending 输入明确 reject 或完成。
- [ ] 编写测试覆盖可重连 runtime、状态快照、安全拒绝和敏感信息脱敏。
