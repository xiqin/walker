# Task 2: 飞书引用上下文透传

## 描述

让飞书平台层把解析出的 `parentId` 放到 text 和 command 顶层事件，供 dispatcher 后续引用路由使用。

## 依赖

- 前置 task：无
- 外部依赖：现有 Lark 消息事件结构和 `parseMessageEvent`

## 涉及文件

| 操作 | 文件路径 | 说明 |
|------|----------|------|
| 修改 | `src/platform/feishu/platform.js` | 在 `_handleMessageEvent` 构造 text/command 事件时加入 `parentId` |
| 修改 | `test/feishu-platform.test.js` | 增加 text、command、缺失 parent_id 的事件透传测试 |

## 复杂度

low，原因：现有 `parseMessageEvent` 已解析 `parentId`，只需顶层事件透传和兼容性测试。

## 实现步骤

- [ ] 为 text 消息测试添加带 `msg.parent_id` 的事件，断言 `onMessage` 顶层 `parentId` 等于该值。
- [ ] 为 slash command 测试添加带 `msg.parent_id` 的事件，断言 `type=command` 且顶层 `parentId` 保留。
- [ ] 为缺失 `parent_id` 的事件保留现有正常调用断言。
- [ ] 在 `FeishuPlatform._handleMessageEvent` 的 text 与 command payload 中加入 `parentId: parsed.parentId`。
