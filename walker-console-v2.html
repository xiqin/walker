飞书命令参考
/new [agent] [title] [--cwd <path>]创建新 session 并绑定当前会话，可指定项目工作目录
/list列出当前 route 下所有 session（含"设为焦点"按钮）
/use <id>切换当前 route 的焦点
/use off移除焦点 session（保留其他）
/current查看当前绑定的 session
/status（/ps）查看 session、Agent、状态、模型、cwd、运行时长
/cancel取消正在执行的 turn，session 回到 idle
/clear新建空上下文并保留旧会话（需先 /cancel）
/stop停止当前 session
/delete <id>删除指定 session
/agents列出可用 Agent 类型
/help命令帮助
